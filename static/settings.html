API settings

API token

Send this token as Authorization: Bearer <token> on every request. Regenerating invalidates the old token immediately.

API reference

The external API lives under /api/ (reachable without SSO). Every request needs Authorization: Bearer <token> and uses JSON bodies; it only supports these two calls.

Add a transaction

POST /api/transactions

Field Required Notes
amount yes Signed: negative is an expense, positive is income; 0 is rejected.
details yes The description; also used for category suggestions.
currency yes One of the currencies listed in the Constants sheet.
date no YYYY-MM-DD; defaults to today.
notes no Optional single line.
category no When omitted, the app assigns one from history (see below). 

            

                With a category, the response is 201 {"transaction":{...}}. Without one, a confident
                match adds "assignedCategory" and a short-lived "editToken"; otherwise
                the request fails with 422 and the candidate "suggestions", so the client
                can retry with an explicit category.
            


            
Correct an assigned category

            
PATCH /api/transactions/<editToken> with {"category":"..."}.

            

            

                The edit token only works for the transaction it was issued for and only changes the category.
                A successful correction changes the transaction's id, so the token is consumed (retrying returns
                409); an invalid category is rejected and the token stays usable.
            


            
Errors

            

                
                    

                        Status
                        Meaning
                    

                
                
                    

                        401
                        Missing or invalid API token, or an invalid/expired edit token.
                    

                    

                        400
                        Invalid input, including a zero amount or a category that doesn't fit the transaction's kind.
                    

                    

                        422
                        No category was supplied and none could be assigned confidently; the body lists the
                            suggestions.
                    

                    

                        409
                        The edit token was already used, or the transaction changed on disk.
