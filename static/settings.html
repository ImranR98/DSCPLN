API settings

API token

Send this token as Authorization: Bearer <token> on every request. Regenerating invalidates the old token immediately.

API reference

The external API lives under /api/ (reachable without SSO). Every request needs Authorization: Bearer <token> and uses JSON bodies; it only supports these two calls.

Find a category

GET /api/categories?details=<text>&kind=expense|income

Returns every category for the kind, grouped as in the Constants sheet and best match first, each with a score between 0 and 1 (0 means no match). Without details the list is un-scored, and without kind it returns every group — so a plain GET /api/categories is the "list categories" call.
